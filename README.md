# Paulus S. Firmanto — Personal Website

Responsive static portfolio built with HTML, CSS, and vanilla JavaScript. No build tools or package installation required.

## Publish with GitHub Pages
1. Create a new public GitHub repository, e.g. `paulus-firmanto-website`.
2. Upload the **contents** of this folder to the repository root. `index.html` must be at root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for the published URL to appear in the Pages settings.

## Files
- `index.html` — website content and structure
- `styles.css` — responsive styling
- `script.js` — mobile menu and dynamic copyright year
- `assets/` — seven supplied book-cover images

## Before publishing
Review role dates, metrics, and descriptions for accuracy. Add verified Gramedia product URLs to book cards when available; no purchase URLs have been invented. Add a professional portrait if desired. The site uses Google Fonts, but remains readable if they fail to load.

## Optional custom domain
If you own `paulusfirmanto.com`, configure it in **Settings → Pages → Custom domain** and follow GitHub's DNS instructions.
